The circulant kernel `circulants/circ.c` is the search code used in the run (unchanged). It tests one set per dihedral
orbit (valid for symmetric circulants). The Python re-check in `rescan.py` tests every set without using the symmetry.
`rescan.py` writes the field tables itself (GF(4) = F_2[x]/(x^2+x+1), GF(8) = F_2[x]/(x^3+x+1), GF(9) = F_3[x]/(x^2+x+2)).

`./run.sh` replays everything except the two long scans (about 5 minutes; `./run.sh full` about 12 minutes).

`codetables/compare_codetables.py` reads the cached pages as data (it parses the printed stabilizer matrices) and uses its
own GF(8) arithmetic. A negative result of its equivalence test proves nothing by itself: it tries only local Cliffords that act in the
same way on every party, together with multipliers, the Frobenius map and scaling. `codetables/lc_invariant.py` supplies the
inequivalence proof for n = 15 (its docstring states the invariant and why local Clifford operations preserve it).
